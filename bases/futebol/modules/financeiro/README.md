# Modulo Financeiro

Modulo financeiro geral para bases e projetos.

## Primeira versao

- Categorias financeiras.
- Lancamentos de entrada e saida.
- Identificacao de quem pagou ou recebeu.
- Integracao opcional com outros modulos, como jogadores.
- Status pendente, pago e cancelado.
- Resumo de entradas, saidas e saldo.

## Ideia futura

Este modulo pode evoluir para mensalidades, assinaturas, doacoes, caixa, contas a pagar, contas a receber e relatorios por plano.
