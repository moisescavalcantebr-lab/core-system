# Treino

Modulo aposentado. As formacoes sao organizadas em Meu Time e os jogos de treino ficam em Competicoes e Partidas.

O manifesto nao publica menu nem executa schema. Os endpoints antigos apenas redirecionam para Meu Time, preservando links existentes e sem alterar tabelas legadas. Arquivos de compatibilidade sao mantidos para atualizacoes de projetos ja instalados.
