# Modulo Classificacao

Modulo geral para rankings e tabelas de classificacao.

Cada tabela define seus proprios campos ativos. Assim a mesma estrutura pode atender futebol, torneios, rankings, concursos, grupos e outros segmentos.

## Primeira versao

- Cria tabelas de classificacao.
- Permite escolher campos ativos.
- Permite cadastrar linhas manualmente.
- Ordena por posicao, pontos, score ou nome.

## Ideia futura

Depois este modulo pode receber calculo automatico vindo de partidas, inscricoes ou resultados, mas a versao inicial fica manual para ser facil de adaptar.
