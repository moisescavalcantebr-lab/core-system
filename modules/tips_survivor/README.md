# Tips Survivor

Modulo principal para competicoes de palpites esportivos em modo survivor.

O MVP usa tokens internos sem saque, compra, venda ou conversao financeira. A proposta e manter o produto como entretenimento, ranking, jornada, vidas e pontos.

Primeira fase:

- estrutura SQL
- dashboard admin
- competicoes
- partidas
- rankings
- tokens internos
- configuracoes

Fluxos publicos, mercado interno e premiacoes patrocinadas entram em fases posteriores.
