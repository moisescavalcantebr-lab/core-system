# Agentes Operacionais do Core

Esta pasta organiza papeis de trabalho para manter o Core evoluindo sem misturar responsabilidades.

Os agentes nao sao codigo do produto. Eles sao guias para abrir tarefas no Codex, revisar mudancas e manter o fluxo local, Docker, GitHub e servidor alinhado.

## Fluxo Oficial

1. Alterar no VS Code/local.
2. Testar no Docker local.
3. Revisar arquivos sensiveis e gerados.
4. Commitar no GitHub.
5. Fazer deploy para o servidor.
6. Validar o servidor.

## Agentes

- `core.md`: estrutura principal, banco, bootstrap, paginas e seguranca.
- `deploy.md`: Docker, servidor, Cloudflare, GitHub e backups.
- `modulos.md`: modulos, addons, bases e sincronizacao.
- `ux-mobile.md`: visual, responsividade e experiencia.
- `qa.md`: checklist de validacao antes de deploy.

Use estes arquivos como ponto de partida para pedir tarefas mais objetivas no Codex.
